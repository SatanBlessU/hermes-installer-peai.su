# hermes-installer-peai.su
Automated install hermes agent and hermes web ui

### install
`` wget -qO- https://raw.githubusercontent.com/SatanBlessU/hermes-installer-peai.su/main/install.sh | sudo bash ``

### install with api token 
`` curl -fsSL https://raw.githubusercontent.com/<USER>/<REPO>/main/install.sh | sudo bash -s -- --apikeypeai "sk-ai-ваш_ключ_здесь" ``

### uninstall
`` curl -fsSL https://raw.githubusercontent.com/SatanBlessU/hermes-installer-peai.su/main/uninstall.sh | sudo bash ``
